Replay executes without inference

replayArtifact has no API, provider or planner dependency. It checks schema, original bytes, evidence digests, compiler and runtime asset lock, then executes compatible jobs serially in saved order. The verifier recomputes status and compares deterministic fields. Before the channel transfers, a credential-free PROBE / HOST_READY bootstrap validates the exact frame and both origins; the host accepts one CONNECT. Failure or cancellation returns an explicit outcome; original evidence is never rewritten.
