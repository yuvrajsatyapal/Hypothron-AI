Local persistence has an explicit boundary

LocalStore creates the database only with explicit persistence consent. Existing inventory reads support saved history without restoring unsaved data. App-origin scripts can read stored data; no encryption or permanent-storage guarantee. Workers improve responsiveness; the separate origin and restricted IR preserve execution isolation.
