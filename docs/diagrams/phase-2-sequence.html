HYPOTHRON AI · PHASE 2 · IMPLEMENTED

Creation, inference and local execution

Time runs downward. Clarification can interrupt before any job and requires a fresh answer/key. The evidence-driven branch repeats within six jobs and twelve attempts. SSE observes committed events in parallel and carries no key. A lost creation ACK is retried with the same request ID. A lost job-ledger write is reconciled from its checkpointed UUID. A reserved attempt with no cached reply becomes BILLING_UNKNOWN rather than automatic retry.
