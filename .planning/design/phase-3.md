# Phase 3 evidence workspace extension

Preserve the foundation tokens, control/evidence layout, responsive stacking and labelled native controls. Version 1 USD/UTC remains the default. An explicit advanced-contract checkbox reveals v2 currency (USD/EUR exact cents or JPY exact yen), timezone (UTC or fixed offset), null policy and required comma-separated grain keys. Period boundaries retain inclusive start / exclusive end and must use the selected offset. Do not imply IANA/DST support.

Optional lookup CSV remains in browser memory. Reveal source/lookup key, cardinality and expected source population. An explicit approval checkbox authorizes only the displayed derived join; changing lookup keys, cardinality, population or source invalidates join approval. Editable controls do not replace the displayed executed contract. Source bytes stay immutable and replay uses both original contract and original lookup snapshot. No lookup rows enter provider metadata or uploads.

Results display the executed version/currency/timezone/null semantics, paired engine diagnostics and status separately from CLIENT_REPORTED provenance. Investigation jobs retain the exact approved v2 contract and submit its bounded diagnostics. Extra datasets are unsupported for a relationship contract because its lookup and population approval belong to the original source. Errors are text; no model content is interpreted as HTML.

Structured reports will extend the existing report region with findings, evidence references, observed/arithmetical relation labels and accessible tabular/chart equivalents. Existing privacy consent, cancellation and memory-only credentials remain unchanged. Design acceptance: keyboard/native labels, narrow-screen overflow, clear monetary scale, and consent before derived execution.

Report detail design: each observed finding carries an evidence anchor, contract hash/version, dataset hash, currency, independent SQL/Pandas amount/count, verification status and provenance. Disputed/inconclusive findings remain visible with both sides and are excluded from supported claims. An accessible signed engine-comparison SVG accompanies an exact monetary table; bar positions use integer-rational scaling, while zero, negative and undefined values are explicit. Chart labels convey that agreement does not establish causality or server attestation. Validated claim templates render as plain React text. Model content never becomes markup. Citation links target evidence anchors. On narrow screens chart SVG fits its container and table text wraps; no new fonts/colors/layout system.
