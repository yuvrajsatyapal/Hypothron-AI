# Investigation workspace extension — Phase 2

Extend the existing evidence workspace below the local calculation. Keep the foundation tokens and explicit executed metric. Before AI Start, require a local result and checkbox consent naming the transmitted question, column names, hashes, metric contracts and bounded aggregate evidence. Raw rows remain local. Provider/model and password key fields are memory only; clear key after each request segment/pause/completion. No saved settings or fake provider prices.

A question field starts a bounded investigation. Up to two extra CSVs use the same visible approved metric; locally profile/calculations complete before descriptors are sent. Show their names locally only. Backend job plans must exactly match an approved in-memory snapshot contract before execution. A clarification panel asks for an answer and fresh key. Resume reconnects an existing memory-held run; a full reload loses the demo token and requires a later opt-in saved bundle, not hidden persistence.

Show hypothesis/evidence/report text with status and CLIENT_REPORTED provenance, event stream progress, and actionable sanitized errors. Cancel aborts local execution and requests backend cancellation. Stop after failed/terminal state; never fabricate an empty successful result. Existing local replay remains zero inference. Controls are disabled while an operation owns the executor; inputs stay labelled and keyboard usable. aria-live reports progress. No model/dataset text is interpreted as HTML.

Design gate: review implemented consent, errors, clarification, cancellation and narrow-screen overflow before Phase2 exit. Diagram styling does not change UI tokens.
